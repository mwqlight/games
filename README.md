# 小游戏集合

一个基于Vue 3和Spring Boot的小游戏集合项目，包含多种经典游戏。

## 功能特性

### 游戏分支清单

每个游戏都有独立的开发分支，分支名称与游戏名称对应关系如下：

| 分支名称                | 游戏名称          | 游戏说明                                                                 |
|-------------------------|-------------------|--------------------------------------------------------------------------|
| game-backgammon         | 跳棋              | 玩家通过“跳子”的方式，将自己的所有棋子最快移动到对角阵营。               |
| game-blackjack          | 十点半            | 玩家通过要牌使手中牌的点数之和尽量接近10点半（花牌为半点），超过则爆牌输。 |
| game-card-game          | 纸牌游戏          | 包含多种纸牌游戏玩法，如抽乌龟、钓鱼等。                                 |
| game-checkers           | 西洋跳棋          | 双方在棋盘上移动棋子，吃掉对方所有棋子者胜。                             |
| game-chess              | 国际象棋          | 遵循国际标准规则，通过不同兵种的配合，目标是“将死”对方的王。             |
| game-chinese-chess      | 象棋              | 遵循传统中国象棋规则，双方移动不同棋子，以将死对方的将（帅）为目标。     |
| game-connect-four       | 四子棋            | 双方轮流在7列6行的棋盘上放置棋子，先连成四子者胜。                       |
| game-gobang             | 五子棋            | 双方轮流落子，先将五颗同色棋子连成一线（横、竖、斜）者胜。               |
| game-international-chess| 国际象棋（备用）  | 与game-chess分支功能相同，作为备用分支。                                 |
| game-mahjong            | 麻将              | 包含四川麻将、二人麻将等多种玩法。                                       |
| game-minesweeper        | 扫雷              | 经典单人游戏，通过点击格子找出所有地雷。                                 |
| game-monopoly           | 大富翁            | 经典多人策略游戏，通过购买土地和收取租金成为富翁。                       |
| game-othello            | 黑白棋（奥赛罗）  | 在8x8棋盘上，通过落子将对方棋子夹在中间并翻转为己方颜色，终局时棋子多者胜。 |
| game-poker              | 扑克              | 包含斗地主、通比牛牛、三公等多种扑克游戏玩法。                           |
| game-puzzle             | 拼图              | 经典拼图游戏，将打乱的图片拼接成完整的图像。                             |
| game-risk               |  Risk游戏         | 多人策略游戏，通过占领领土和消灭敌人来获得胜利。                         |
| game-rules              | 游戏规则          | 存放所有游戏的规则说明文档。                                             |
| game-scrabble           | 拼字游戏          | 玩家通过字母牌拼出单词，得分最高者胜。                                   |
| game-snake              | 贪吃蛇            | 经典贪吃蛇游戏，控制蛇吃食物并避免撞墙或撞到自己。                       |
| game-sudoku             | 数独              | 经典数字逻辑游戏，填满9x9网格，每行、每列和每个3x3小格都包含1-9的数字。   |
| game-tetris             | 俄罗斯方块        | 经典益智游戏，控制下落的方块填满一行得分。                               |
| game-tic-tac-toe        | 井字棋            | 双方在3x3网格轮流画“○”和“×”，先连成一线者胜。                           |
| feature-init            | 项目初始化        | 项目基础架构和通用功能开发。                                             |

### 已实现的游戏

1. **井字棋游戏** (game-tic-tac-toe)
   - 支持双人对战和AI对战
   - 简单的AI策略
   - 游戏状态显示
   - 重新开始功能

2. **五子棋游戏** (game-gobang)
   - 支持双人对战和AI对战
   - 简单的AI策略
   - 游戏状态显示
   - 重新开始和悔棋功能

3. **象棋游戏** (game-chinese-chess)
   - 支持双人对战和AI对战
   - 完整的象棋规则
   - 游戏状态显示
   - 重新开始、悔棋和翻转棋盘功能

### 游戏配置

- 游戏难度设置
- AI对战开关
- 游戏音效开关
- 背景音乐开关
- 游戏速度设置

## 技术栈

### 前端

- **Vue 3**: 渐进式JavaScript框架
- **Element Plus**: 基于Vue 3的组件库
- **Vue Router**: Vue.js的官方路由管理器
- **Vite**: 下一代前端构建工具

### 后端

- **Spring Boot**: 基于Spring的Java应用框架
- **Spring Data JPA**: Java持久化API
- **H2 Database**: 嵌入式数据库
- **Spring Security**: 安全框架

## 快速开始

### 环境要求

- Node.js 16+ 
- Java 17+ 
- Maven 3.8+ 

### 启动前端服务

```bash
cd game-frontend
npm install
npm run dev
```

前端服务将在 http://localhost:3000 启动

### 启动后端服务

```bash
cd game-backend
mvn spring-boot:run
```

后端服务将在 http://localhost:8080/api 启动

## 游戏说明

### 井字棋游戏

1. 点击棋盘上的空格放置棋子
2. 先连成三子者获胜
3. 可以选择双人对战或AI对战

### 五子棋游戏

1. 点击棋盘上的空格放置棋子
2. 先连成五子者获胜
3. 可以选择双人对战或AI对战
4. 支持悔棋功能

### 象棋游戏

1. 点击棋子选择，再次点击合法位置移动
2. 遵循中国象棋规则
3. 可以选择双人对战或AI对战
4. 支持悔棋和翻转棋盘功能

## 配置说明

在游戏配置页面可以设置：

- **游戏难度**: 简单、中等、困难
- **AI对战**: 开启/关闭AI
- **游戏音效**: 开启/关闭音效
- **背景音乐**: 开启/关闭背景音乐
- **游戏速度**: 1-10级调节
